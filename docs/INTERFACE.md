# v1.1 界面指南

同屏 Lite 使用浏览器，也可以在支持安装的 Chrome / Edge 中以 PWA 形式放到桌面。安装后的应用使用相同的服务器，屏幕和麦克风仍需浏览器授权。

## 大厅

顶部的「创建房间」「加入房间」切换两种操作。收到完整邀请链接时，直接打开链接会自动选择加入；填写昵称并按 Enter 也会加入这个房间，不会另开新房间。关闭「加入时开启麦克风」，可以只看和听。

创建需要管理员口令时才显示口令输入框。创建或加入期间按钮显示处理状态，网络或授权错误会通过消息提示，不会悄悄退出。

## 房间

| 位置 | 显示与操作 |
| --- | --- |
| 顶部 | 房间编号、本次停留时间、连接状态、邀请和离开 |
| 左侧成员 | 昵称、静音与共享状态、单独连接状态；收到真实语音电平时显示音量条与说话高亮 |
| 中间画面 | 当前分享者画面；未分享时显示邀请和共享入口 |
| 画面下方 | 麦克风、暂停或恢复收听、共享或停止屏幕、共享声音、全屏 |
| 下方网络卡片 | 所有连接合计的上传与下载、最慢网络往返、最近 60 秒流量趋势 |
| 右侧设置 | 自己共享时的画质、朋友语音音量、共享电脑声音音量、连接详情 |

没有网络样本时数据为「—」；没有真实语音输入时成员不会模拟说话。音量条用于观察输入强弱，不是专业响度计。说话检测有短暂保持，避免停顿时频繁闪烁；环境噪声也可能影响指示。

点击画面右上角「专注模式」，扩大画面并收起两侧面板；再次点击或按 Esc 恢复。点击「全屏」进入浏览器全屏。手机上先显示画面和操作，成员与设置在下方，页面可以滚动。

其他人已经共享时，「共享屏幕」会显示「朋友正在共享」并不可点击；对方停止后自动恢复。

## 声音的三个独立控制

- **麦克风**：决定别人是否听到你。关闭会停止麦克风采集，不影响你共享的视频声音。
- **收听**：暂停或恢复你听到的所有远端声音。麦克风继续按原状态发送，暂停收听不代表别人听不到你。
- **共享声音**：决定别人是否听到你分享的电脑声音。只有捕获到电脑音轨后才可操作。

右侧的两条音量滑块只影响本机播放，不改变其他人的音量。分享视频时，建议选择浏览器标签页并勾选音频；是否能分享整个桌面的系统声音以浏览器弹窗为准。

## 安装与更新

顶部出现「安装到桌面」按钮时即可安装；也可以从 Chrome / Edge 的浏览器菜单安装应用。其他浏览器仍可直接打开网址。安装入口的实际位置受浏览器版本、系统和安装状态影响。

服务工作线程只缓存公开应用外壳与图标，优先从网络获取最新资源；不缓存房间路径、API、信令或音视频。通话始终需要联网。服务器更新后，关闭应用窗口并重新打开，可以加载新版本。

本版本已在真实 Chromium 中验证三位参与者、六个语音方向、画面接收、语音电平、音量控制、换人共享与多种窗口宽度，并保存 [真实截图](SCREENSHOTS.md)。浏览器实际安装、系统屏幕授权弹窗、物理设备和跨运营商连接仍需在目标设备验收。
